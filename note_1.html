📁 步驟 1：建立 GitHub 帳號與倉庫

前往 GitHub.com。點擊右上角「+」→ New repository。

名稱建議：你的帳號.github.io，勾選 Add a README file，點擊 Create。

💡 這是你的個人網站基地！

🤖 步驟 2：用 Gemini 生成導航欄

輸入 Prompt：

幫我建立一個 nav.html，包含首頁、關於我、聯繫方式。
白色背景、置頂固定、簡約風格。

📄 步驟 3：生成各頁面內容

利用 Gemini 生成 index.html，並在開頭引入 nav.html。

📤 步驟 4：開啟 Pages

在 Settings → Pages 中開啟部署，約一分鐘後即可看見網站上線。

🎉 恭喜完成數位資產部署！
