📁 步驟 1：註冊 GitHub 帳號 + 建立倉庫 + 找到你的網站網址

🔹 什麼是 GitHub？
GitHub 是一個免費存放程式碼的地方，還可以把你的網站免費發佈到網路上！

1.1 註冊 GitHub 帳號

👉 前往 https://github.com

  • 點擊右上角 Sign up
  • 輸入 Email、密碼、使用者名稱
  • 完成驗證後就擁有帳號了！
💡 使用者名稱會影響你的網站網址，建議用英文或數字，例如：seira0972-glitch

1.2 建立倉庫（Repository）

倉庫就像一個「資料夾」，放你網站的檔案。

  • 登入後，點擊右上角 「+」→ New repository
  • Repository name 輸入：你的帳號.github.io
    ⚠️ 注意：要把「你的帳號」換成你註冊時的使用者名稱！
    例如你的帳號是 seira0972-glitch，就輸入 seira0972-glitch.github.io
  • 勾選 Add a README file
  • 保持 Public（公開）
  • 點擊 Create repository

1.3 找到你的網站網址

倉庫建立後，你的網站網址就是：

https://你的帳號.github.io/

例如：https://seira0972-glitch.github.io/

⚠️ 目前網站還看不到東西，因為還沒有上傳任何檔案！
我們會在第 2、3 步用 Gemini 生成檔案，第 4 步上傳。
💡 小技巧：記住這個網址規則 — 你的帳號.github.io 就是你的免費網站網址！

🤖 步驟 2：用 Gemini 生成共用導航欄 (nav.html)

打開 Google Gemini，輸入以下提示詞：

幫我建立一個 nav.html 檔案，裡面是網站的導航欄，包含：
- 首頁 (index.html)
- 關於我 (about.html)
- 聯繫方式 (contact.html)
- 其他分頁 (other.html)

樣式：白色背景、置頂固定、hover 底線效果、手機響應式。
請給我完整的 HTML + CSS 程式碼。
💡 導航欄先做好，之後每個頁面都可以共用，修改一次全部同步。

📤 步驟 4：上傳檔案並開啟 GitHub Pages

上傳檔案：

  • 回到你的 GitHub 倉庫（例如 seira0972-glitch.github.io）
  • 點擊 Add file → Create new file
  • 檔名輸入 nav.html，貼上 Gemini 生成的程式碼 → Commit changes
  • 重複步驟，依序建立 index.html、about.html、contact.html、other.html

開啟 GitHub Pages：

  • 進入倉庫 → 點擊上方的 Settings
  • 左邊選單找到 Pages
  • 在 Branch 選擇 main，點擊 Save
  • 等待 1-2 分鐘，網站就上線了！
🎉 網站網址就是：https://你的帳號.github.io/ 或 https://你的帳號.github.io/倉庫名/

✨ 步驟 5：用 Gemini 優化與擴充

• 修改內容： 把網站網址貼給 Gemini，請它幫你優化設計

• 新增頁面： 在 nav.html 加連結，再用 Gemini 生成新頁面

• 自訂網域： 想用自己買的網址？在 Pages 設定中可以綁定

• 聯絡表單： 請 Gemini 幫你嵌入 Formspree，讓訪客可以寄信給你
