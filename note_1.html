📁 步驟 1：建立 GitHub 帳號與倉庫

前往 GitHub 註冊。點擊右上角「+」選 New repository。

Repository name 設定為 你的帳號.github.io。這將是你未來的永久網址。

💡 勾選 Add a README file 可以讓倉庫初始化更順利。

🤖 步驟 2：利用 Gemini 生成導航欄

在 Gemini 輸入提示詞，獲取 nav.html 的程式碼：

幫我寫一個簡約的導航欄，背景純白，連結包含：首頁、關於、聯絡。
需要支援手機版隱藏選單。
💡 這是網站的心臟，修改一次，全站同步更新。

📄 步驟 3：生成頁面與內容填充

利用 Gemini 生成各頁面的 index.html 與 about.html。請記得在程式碼中加入 fetch 語法來引入 nav.html。

📤 步驟 4：上傳檔案與 Settings 設定

點擊 Add file -> Upload files，將所有檔案上傳。最後到 Settings -> Pages 將 Branch 改為 main 並儲存。

🎉 大功告成！約等待一分鐘，網站就會在 你的帳號.github.io 上線。

恭喜！你已完成第一座數位資產的建立。
