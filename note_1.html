📁 步驟 1：建立 GitHub 帳號與倉庫

前往 GitHub.com 註冊免費帳號。點擊右上角「+」→ New repository。

Repository name 輸入：你的帳號.github.io，勾選 Add a README file，保持 Public，點擊 Create repository。

💡 這個名稱會直接成為你的網站網址！

🤖 步驟 2：用 Gemini 生成共用導航欄

打開 Google Gemini，輸入以下提示詞：

幫我建立一個 nav.html 檔案，裡面是網站的導航欄，包含：
- 首頁 (index.html)
- 關於我 (about.html)
- 聯繫方式 (contact.html)
- 其他分頁 (other.html)

樣式：白色背景、置頂固定、hover 底線效果、手機響應式。
請給我完整的 HTML + CSS 程式碼。
💡 導航欄先做好，之後每個頁面都可以共用，修改一次全部同步。

📄 步驟 3：用 Gemini 生成各頁面內容

繼續跟 Gemini 對話，用以下提示詞生成其他頁面：

幫我生成 index.html，內容包含：
- 頁面頂部載入 nav.html（用 fetch 方式）
- 一個漂亮的歡迎區塊（英雄區塊）
- 自我介紹區塊
- 頁尾
風格：現代簡潔、藍紫漸層、響應式設計
💡 提示詞越詳細，Gemini 生成的結果越接近你想要的樣子！

📤 步驟 4：上傳檔案並開啟 GitHub Pages

上傳檔案： Add file → Create new file，依序建立 nav.html、index.html、about.html、contact.html、other.html，貼上 Gemini 生成的程式碼。

開啟 Pages： Settings → Pages → Branch 選 main → Save

等待 1-2 分鐘，網站就會在 https://你的帳號.github.io/ 上線！

🎉 每次修改檔案並 Commit，網站會自動更新。

🎉 恭喜！你現在有自己的網站了！
