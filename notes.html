🔓 完整教學：用 ChatGPT 做網站

🧭 步驟 1：用 ChatGPT 生成共用導航欄 (nav.html)

導航欄是所有頁面的「目錄」，先建立它，之後每個頁面都能共用。

打開 ChatGPT，輸入以下提示詞：

幫我建立一個 nav.html 檔案，裡面是網站的導航欄，包含：
- 首頁 (index.html)
- 關於我 (about.html)
- 聯繫方式 (contact.html)
- 其他分頁 (other.html)

樣式要求：
- 白色背景
- 置頂固定 (sticky)
- hover 時有底線效果
- 手機版要響應式（選單項目水平排列，太小螢幕時適當縮小間距）

請給我完整的 HTML + CSS 程式碼，直接可以複製貼上使用。

ChatGPT 會生成類似這樣的程式碼：

<nav style="background: white; padding: 15px 20px; position: sticky; top: 0; text-align: center;">
    <a href="index.html" style="color: #333; text-decoration: none; margin: 0 15px;">首頁</a>
    <a href="about.html" style="color: #333; text-decoration: none; margin: 0 15px;">關於我</a>
    <a href="contact.html" style="color: #333; text-decoration: none; margin: 0 15px;">聯繫方式</a>
    <a href="other.html" style="color: #333; text-decoration: none; margin: 0 15px;">其他分頁</a>
</nav>

<style>
    nav a:hover { color: #667eea; border-bottom: 2px solid #667eea; }
    @media (max-width: 768px) {
        nav a { margin: 0 8px; font-size: 14px; }
    }
</style>
💡 為什麼要先做導航欄？因為之後用 ChatGPT 生成每個頁面時，可以直接請它「在頁面頂部載入 nav.html」，確保所有頁面導航一致，以後修改導航只需要改一個檔案。

🤖 步驟 2：用 ChatGPT 生成各頁面內容

使用 ChatGPT 來生成你的網頁程式碼：

範例提示詞（首頁）：

幫我生成一個 index.html 檔案，內容包含：
- 頁面頂部載入 nav.html（用 fetch 方式）
- 一個歡迎區塊
- 自我介紹
- 頁尾
風格：現代簡潔、紫色主色調、響應式設計

同樣的方式，分別生成：

  • about.html — 關於我（自我介紹、經歷）
  • contact.html — 聯繫方式（信箱、社群連結）
  • other.html — 其他分頁（筆記、作品集等）
💡 提示詞越詳細，ChatGPT 生成的結果越接近你想要的樣子！可以不斷對話調整。

📁 步驟 3：建立 GitHub 帳號與倉庫

1. 前往 GitHub.com 註冊免費帳號

2. 點擊右上角「+」→ New repository

3. Repository name 輸入：你的帳號.github.io

4. 勾選 Add a README file，保持 Public，點擊 Create repository

💡 這個名稱會直接成為你的網站網址！

📤 步驟 4：上傳檔案並開啟 GitHub Pages

把 ChatGPT 幫你生成的檔案上傳到倉庫：

  • 點擊 Add file → Create new file
  • 依序建立：nav.html、index.html、about.html、contact.html、other.html
  • 每個檔案貼上 ChatGPT 生成的程式碼 → Commit changes

開啟 GitHub Pages：

  • 進入倉庫 → Settings → Pages
  • 在 Branch 選擇 main，點 Save
  • 等待 1-2 分鐘，網站就會在 https://你的帳號.github.io/ 上線
🎉 恭喜！你的網站已經正式上線了！每次修改檔案並 Commit，網站會自動更新。

✨ 步驟 5：用 ChatGPT 優化設計與擴充頁面

優化設計： 把現有網頁貼給 ChatGPT，請它幫你「優化視覺、加上動畫效果、改善手機版樣式」

新增頁面： 直接在 nav.html 加入新連結，再用 ChatGPT 生成新頁面內容

自訂網域： 在 Pages 設定中填入你的網域，再到網域商設定 DNS

聯絡表單： 請 ChatGPT 幫你嵌入 Formspree 或 Google 表單

// 範例提示詞：
「幫我在 contact.html 加入一個聯絡表單，欄位包含：姓名、Email、訊息，使用 Formspree 接收信件」

🎯 完成！
