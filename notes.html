🔓 完整教學筆記

📁 步驟 1：建立 GitHub 帳號與倉庫

1. 前往 GitHub.com 註冊免費帳號

2. 點擊右上角「+」→ New repository

3. Repository name 輸入：你的帳號.github.io（例如 seira0972-glitch.github.io）

4. 勾選 Add a README file，保持 Public，點擊 Create repository

💡 這個名稱會直接成為你的網站網址！

🌐 步驟 2：建立首頁 index.html

在倉庫內點擊 Add file → Create new file，檔名輸入 index.html，貼上以下代碼：

<!DOCTYPE html>
<html>
<head>
    <title>我的品牌</title>
    <meta charset="UTF-8">
</head>
<body>
    <h1>歡迎來到我的品牌</h1>
    <p>我的第一個 GitHub Pages 網站！</p>
</body>
</html>

點擊 Commit changes 儲存。

📄 步驟 3：新增多個頁面 + 導航欄

重複上述步驟，建立 about.html、services.html、notes.html。

每個頁面都要加上導航欄，讓訪客可以在頁面之間跳轉：

<nav>
    <a href="index.html">首頁</a>
    <a href="about.html">關於</a>
    <a href="services.html">服務</a>
    <a href="notes.html">筆記</a>
</nav>

✨ 進階：可建立 nav.html 用 JavaScript 載入，一處修改全部同步。

⚙️ 步驟 4：開啟 GitHub Pages

1. 進入倉庫 → Settings → Pages

2. 在 Branch 選擇 main，點 Save

3. 等待 1-2 分鐘，網站就會在 https://你的帳號.github.io/ 上線

每次修改檔案並 Commit，網站會自動更新。

🎨 步驟 5：自訂設計與進階功能

自訂設計： 修改 CSS 樣式，使用 v0.dev 或 ChatGPT 生成現代化版面。

自訂網域： 在 Pages 設定中填入你的網域，再到網域商設定 DNS。

聯絡表單： 使用 Formspree 或 Google 表單嵌入。

共用導航欄： 建立 nav.html，用 fetch 載入到所有頁面。

🎉 恭喜！你已經學會用 GitHub Pages 免費建立多頁面品牌官網了！
