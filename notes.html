🔓 完整教學

📁 步驟 1：建立 GitHub 帳號與倉庫

1. 前往 GitHub.com 註冊免費帳號

2. 點擊右上角「+」→ New repository

3. Repository name 輸入：你的帳號.github.io

4. 勾選 Add a README file，保持 Public，點擊 Create repository

💡 這個名稱會直接成為你的網站網址！

🧭 步驟 2：用 ChatGPT 生成共用導航欄

打開 ChatGPT，輸入以下提示詞：

幫我建立一個 nav.html 檔案，裡面是網站的導航欄，包含：
- 首頁 (index.html)
- 關於我 (about.html)
- 聯繫方式 (contact.html)
- 其他分頁 (other.html)

樣式：白色背景、置頂固定、hover 底線效果、手機響應式。
請給我完整的 HTML + CSS 程式碼。
💡 導航欄先做好，之後每個頁面都可以共用，修改一次全部同步。

🤖 步驟 3：用 ChatGPT 生成各頁面內容

範例提示詞（首頁）：

幫我生成 index.html，內容包含：
- 頁面頂部載入 nav.html（用 fetch）
- 歡迎區塊、自我介紹、頁尾
風格：現代簡潔、藍紫漸層、響應式設計

同樣方式生成：about.html、contact.html、other.html

📤 步驟 4：上傳檔案並開啟 GitHub Pages

上傳檔案： Add file → Create new file，依序建立 nav.html、index.html、about.html、contact.html、other.html，貼上 ChatGPT 生成的程式碼。

開啟 Pages： Settings → Pages → Branch 選 main → Save

等待 1-2 分鐘，網站就會在 https://你的帳號.github.io/ 上線！

🎉 每次修改檔案並 Commit，網站會自動更新。

✨ 步驟 5：用 ChatGPT 優化與擴充

• 優化設計： 貼給 ChatGPT 請它「優化視覺、加動畫、改善手機版」

• 新增頁面： 在 nav.html 加連結，再用 ChatGPT 生成新頁面

• 自訂網域： Pages 設定中填入網域，再到網域商設定 DNS

• 聯絡表單： 請 ChatGPT 幫你嵌入 Formspree 表單

🎯 完成！

你現在擁有：共用導航欄 + 多頁面網站 + ChatGPT 輔助生成

隨時可以用 ChatGPT 繼續擴充更多頁面！
