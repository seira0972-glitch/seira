📘 GitHub 多頁面網頁製作筆記

🎯 目標

用 GitHub Pages 免費建立一個多頁面品牌官網，零程式基礎也能完成。

📁 步驟 1：建立 GitHub 倉庫

1. 註冊 GitHub 帳號

2. 點擊 New repository

3. 倉庫名稱輸入：你的帳號.github.io（例如 seira0972-glitch.github.io）

4. 勾選 Add a README file，點擊 Create repository

🌐 步驟 2：建立首頁 (index.html)

1. 點擊 Add file → Create new file

2. 檔名輸入 index.html

3. 貼上 HTML 代碼（可自行設計或使用 AI 生成）

4. 點擊 Commit changes

📄 步驟 3：新增多個頁面

重複上述步驟，建立：

  • about.html - 關於我們
  • services.html - 服務項目
  • notes.html - 筆記 / 文章

💡 每個頁面要有統一的導航欄，讓訪客可以跳轉：

<nav>
    <a href="index.html">首頁</a>
    <a href="about.html">關於</a>
    <a href="services.html">服務</a>
    <a href="notes.html">筆記</a>
</nav>

⚙️ 步驟 4：開啟 GitHub Pages

1. 進入倉庫 → Settings → Pages

2. 在 Branch 選擇 main，點 Save

3. 等待 1-2 分鐘，網站就會在 https://你的帳號.github.io/倉庫名/ 上線

🎨 步驟 5：自訂設計與內容

• 修改 HTML 中的文字、圖片、連結

• 用 v0.dev 或 ChatGPT 生成更專業的版面

• 隨時編輯、Commit，網站會自動更新

💡 進階技巧

✅ 綁定自訂網域：在 Pages 設定中填入你的網域，再到網域商設定 DNS

✅ 使用 AI 生成多頁面：用 v0.dev 分別生成各頁面，保持風格一致

✅ 加入表單：使用 Formspree 或 Google 表單嵌入
