🔓 完整教學：用 AI 做網站

🤖 步驟 1：用 AI 生成網站架構與內容

使用 ChatGPT 或 v0.dev 來生成你的網頁程式碼：

  • ChatGPT：直接輸入需求，例如「幫我生成一個品牌官網的首頁，要有導航欄、Hero 區塊、三個服務卡片，風格現代簡潔」
  • v0.dev：更適合生成 React 元件，也可輸出 HTML/CSS 程式碼

範例提示詞：

請幫我生成一個完整的 index.html 檔案，內容包含：
- 導航欄（首頁、關於、服務、筆記）
- 一個漂亮的 Hero 背景區塊
- 三個服務項目卡片
- 頁尾
風格：現代簡潔、紫色主色調、響應式設計
💡 提示詞越詳細，AI 生成的結果越接近你想要的樣子！

📁 步驟 2：建立 GitHub 帳號與倉庫

1. 前往 GitHub.com 註冊免費帳號

2. 點擊右上角「+」→ New repository

3. Repository name 輸入：你的帳號.github.io

4. 勾選 Add a README file，保持 Public，點擊 Create repository

💡 這個名稱會直接成為你的網站網址！例如：seira0972-glitch.github.io

📤 步驟 3：將 AI 生成的檔案上傳 GitHub

把 AI 幫你生成的 HTML 檔案上傳到倉庫：

  • 點擊 Add file → Create new file
  • 檔名輸入 index.html
  • 貼上 AI 生成的程式碼 → Commit changes
  • 重複步驟，上傳 about.html、services.html、notes.html
✨ 如果 AI 只給了你一個頁面，可以再用同樣的方式生成其他頁面，記得保持導航欄一致。

🚀 步驟 4：開啟 GitHub Pages 發佈網站

1. 進入倉庫 → Settings → Pages

2. 在 Branch 選擇 main，點 Save

3. 等待 1-2 分鐘，網站就會在 https://你的帳號.github.io/ 上線

🎉 恭喜！你的 AI 生成網站已經正式上線了！

每次修改檔案並 Commit，網站會自動更新，無需任何額外操作。

✨ 步驟 5：用 AI 優化設計與進階功能

優化設計： 把現有網頁貼給 ChatGPT，請它幫你「優化視覺、加上動畫效果、改善手機版樣式」

自訂網域： 在 Pages 設定中填入你的網域，再到網域商設定 DNS

聯絡表單： 請 AI 幫你嵌入 Formspree 或 Google 表單

共用導航欄： 請 AI 幫你寫一個 nav.html 搭配 fetch 載入，一處修改全部同步

// 範例提示詞：
「幫我建立一個 nav.html 檔案，裡面放導航欄的 HTML，
然後教我怎麼用 JavaScript 把這個導航欄載入到所有頁面」
